Política de Privacidade — TikTok Factory

Última atualização: 29/07/2026

1. Coleta de dados

Esta aplicação ("TikTok Factory") não coleta, armazena, processa ou compartilha dados pessoais de terceiros ou de usuários do TikTok. Ela não possui interface pública, cadastro de usuários, nem qualquer forma de coleta de dados de visitantes ou do público.

2. Dados utilizados pela aplicação

A aplicação utiliza exclusivamente credenciais de autenticação (OAuth) da própria conta do desenvolvedor no TikTok (@fatoshistoricosaqui), fornecidas diretamente pelo TikTok através de sua API oficial (Content Posting API), com a única finalidade de publicar vídeos gerados automaticamente nessa mesma conta.

3. Armazenamento

As credenciais de autenticação (tokens de acesso) são armazenadas de forma local e privada, em ambiente controlado pelo próprio desenvolvedor, e não são compartilhadas com terceiros.

4. Compartilhamento de dados

Esta aplicação não compartilha nenhum dado com terceiros, anunciantes ou outros serviços, além da comunicação direta e necessária com a API oficial do TikTok para a publicação de conteúdo.

5. Alterações nesta política

Esta política pode ser atualizada a qualquer momento, sem aviso prévio, para refletir mudanças no funcionamento da aplicação.
